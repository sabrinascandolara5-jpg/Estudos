# Lâmina P2 — Patologia e Imunologia

Plataforma de estudo para a P2 de Agressão e Defesa II.

Abra `plataforma/index.html` no navegador. Conteúdo em `plataforma/data/`:
- `topics.js` — resumos por tema
- `questions.js` — questões de caso clínico com comentário
- `cases.js` — casos discursivos com resposta-modelo
- `flashcards.js` — flashcards
